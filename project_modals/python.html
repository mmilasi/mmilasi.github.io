PhotoGallery - Galleria Fotografica con PyQt

«Un'applicazione desktop per esplorare immagini, progettata con cura e attenzione all'usabilità»

Genere: Applicazione GUI, Visualizzazione immagini

Linguaggi utilizzati: Python, PyQt

Link: github.com/mmilasi/photoGallery

Il Project Work realizzato nell'ambito del corso Cloud DevOps che frequento presso l'ITS Adriano Olivetti, sotto la supervisione dell'Ing. Stefano Castagnoli, ha come obiettivo la creazione di un'applicazione desktop per la visualizzazione di immagini, utilizzando il linguaggio Python e il framework PyQt. L'applicazione è progettata per offrire un'interfaccia utente intuitiva e reattiva, adattandosi dinamicamente alle dimensioni della finestra. Tra le funzionalità implementate vi sono:

  • Caricamento immagini: Supporta PNG, JPG, JPEG
  • Navigazione: Scorri tra le immagini con pulsanti "←" e "→"
  • Zoom: Zoom in/out con pulsanti o rotellina mouse (Ctrl+Rotellina), reset zoom con pulsante "1:1"
  • Rotazione: Ruota immagini di 90° alla volta
  • Like: Aggiungi/rimuovi cuore alle immagini preferite
  • Commenti: Aggiungi descrizioni testuali alle immagini
  • Selezione multipla: Seleziona più immagini per azioni batch
  • Download: Salva singola immagine, crea ZIP per più immagini
  • Eliminazione: Rimuovi immagini singole o multiple
  • Stampa: Stampa direttamente le immagini
  • Temi: Interfaccia chiara/scura personalizzabile
  • Fullscreen: Modalità a schermo intero per la visualizzazione
  • Ricerca visiva: Ricerca l'immagine corrente su Google Lens
La scelta di PyQt come framework è stata motivata dalla sua robustezza e dalla capacità di creare interfacce grafiche moderne e responsive. Il progetto rappresenta un esercizio pratico nell'applicazione di concetti di sviluppo software e design dell'interfaccia utente, consolidando le competenze acquisite durante il percorso formativo.
